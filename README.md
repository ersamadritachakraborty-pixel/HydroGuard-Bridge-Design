## Overview

HydroGuard is a climate-inspired popsicle-stick bridge design (≤ 100 sticks + glue) combined with a clean Java force simulator.

Instead of starting from a standard competition template, the team studied the August 2026 Bhotekoshi–Trishuli floods in Nepal (where 41 of 63 bridges were destroyed) and asked:

> *What structural attributes allowed some bridges to survive?*

The answer became the **HydroGuard Redundant Hybrid Truss**.

---

## Design Philosophy

| Principle | Description |
|---------|-------------|
| **Triangular Stability** | Every panel is a triangle (zero degrees of freedom) |
| **Hybrid Force Path** | Warren diagonals + Howe verticals |
| **Multi-layer Redundancy** | Critical members use 2–3 stick layers |
| **Strong Abutments** | Wide end supports inspired by deep foundations |
